# services/device-gateway — 设备采集网关（独立部署单元）

独立进程，负责麻醉机/监护仪等设备的采集、协议解析、标准化与幂等补传。
与业务应用解耦：设备只采集不控制，网关故障不阻塞临床主流程。

## 边界与约束

- 断网本地缓存 ≥ 4 小时，恢复后按幂等键补传，不丢不重；
- 采集明细落在 `m2_anes` 的采集表，由 M2 模块拥有 schema；
- 协议适配器一设备一实现（防腐层），设备字段变化不外溢；
- 不承载业务规则，不直接对外提供业务 API。
