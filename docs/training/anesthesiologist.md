# 麻醉医师培训（R2 / SYS_ANESTHESIOLOGIST）

> 目标：独立完成术前访视与评估、知情同意/三方核查、术中记录、锁单与修订、PACU 与随访。
> 权限：M2 术前/同意/核查/记录/锁单/修订；申请与排程以查看为主（编辑权限由管理员按岗位
> 另行授予，默认不包含排程写权限）。无权限时按钮不可见/接口 403，属正常。
> 练习环境：演示库（SYNTHETIC），病例见 [`../guides/demo.md`](../guides/demo.md)。

## 1. 登录与班前

1. 打开 `https://<院方域名>/`，登录；首次登录先改密；
2. 首页查看今日台次与待办；左侧"手术申请"（`/m1/applications`）查看申请列表/详情；
3. 左侧"排程工作台"（`/m1/schedule`）查看台次与术间（只读时无保存按钮）；
4. 确认本人数据范围：SELF 只看到本人相关台次；DEPT/ALL 按授权。

> 截图占位 1：首页待办 + 申请详情（合成患者）。

## 2. 术前访视与评估（`/m2/preop`）

1. 从申请进入访视单（`/m2/preop/:applicationId`）；
2. 填写病史、气道评估、ASA 分级；按表单完成 RCRI、Apfel、STOP-BANG；
3. 系统按公开量表计算风险分层（口径见 `docs/modules/m2/README.md` §4–§5，
   阈值可配置，展示值为**辅助**，不替代临床判断）；
4. 填写麻醉计划（方式、监测、备血/特殊准备）；
5. 保存；校验失败按字段提示修正（未来时间/越界/必填）。

> 截图占位 2：访视单评分区与麻醉计划（合成数据）。

## 3. 知情同意与三方核查（`/m2/consent`、`/m2/three-way`）

1. 选择申请 → 生成/查看知情同意记录；确认模板与风险条款；
2. 签署状态必须为 `SIGNED` 且为**当前有效**（最新签署；拒绝/撤销不算）；
3. 三方核查：按 Time-out/Sign-out 填写，标本/植入物核对与问题项如实记录；
4. 核查为 append-only 版本化：修正必须新增版本，不覆盖历史；
5. 锁单前系统会校验"当前有效同意 + 三方核查完成"，缺失会阻止锁单（fail-safe）。

> 截图占位 3：同意签署状态与三方核查表单。

## 4. 术中记录（`/m2/records`）

1. 从台次进入记录单（`/m2/records/:scheduleId`），开始麻醉 → 记录 `ANESTHESIA_START`；
2. 事件/用药/输液/出入量按时间轴录入；补录早于当前时间需填原因；
3. 设备采集自动入时间轴（网关补传带 `ts:BACKFILL` 标记）；异常/可疑数据看质量标记，
   不要手工改设备原始值；需要时在记录中说明；
4. 预警：按提示确认/忽略，处理原因必填（审计不记录自由文本原文）；
5. 抢救：记录人员、用药、事件，保持时间顺序；结束后填写 `ANESTHESIA_END`；
6. 全程至少 1 条时间轴事件，否则无法锁单。

> 截图占位 4：记录单时间轴 + 采集体征 + 预警处理。

## 5. 锁单与修订

### 5.1 锁单

1. 打开记录单"锁单"面板，查看服务端前置清单（三方核查、有效同意、开始/结束时间、
   至少 1 条事件、未锁单）；
2. 逐项确认后提交（`confirmChecklist`）；不确认会被 400 拒绝；
3. 前置不满足返回 409 并逐项列出原因，按提示补齐后重试；
4. 锁单成功：内容只读，生成锁单摘要与签名（当前为模拟 CA，EXT-05）。

### 5.2 修订（锁单后）

1. 进入"修订"→ 新建修订；选择原因码并填写说明（必填）；
2. 系统生成全量快照 + 与上一版差异 + 签名链（`previousSignatureHash`）；
3. 修订版本号递增（revisionNo），历史版本保留可查；
4. 禁止直接改库/绕过修订；锁单后任何写接口均 409。

> 截图占位 5：锁单前置清单 + 修订差异页。

## 6. PACU 与术后随访

1. PACU（`/m2/pacu/:recordId`）：入室、Aldrete 评分序列、转出；阈值默认 9（院方确认后配置），
   未达阈值转出返回 409；
2. 转出用 SBAR 交接，记录去向与接收人；
3. 随访（`/m2/followups/:recordId`）：24h/48h NRS、PONV、并发症、PCA 参数与反馈；
4. 自由文本避免写入无关患者标识；导出/截屏遵守脱敏要求。

## 7. 常见错误与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 锁单 409 | 同意未 SIGNED/三方核查未完成/无开始结束/无事件 | 按返回的 `details[]` 逐项补齐，不要反复点 |
| 锁单 400 | 未勾选确认清单 | 核对后勾选再提交 |
| 锁单后再保存 409 | 已锁单只读 | 走"创建修订"，不要刷新重试 |
| 修订 400 | 原因码非法/说明缺失 | 选合法原因码并填写说明 |
| 事件保存 400 | 未来时间超容差/补录缺原因 | 校正时间或填写补录原因 |
| 同意读取不到 | 无有效 SIGNED（拒绝/撤销/等待签署） | 重新签署；锁单 fail-safe 不会放行 |
| 预警无法关闭 | 无处理权限/原因未填 | 填原因；权限问题找管理员 |
| 转出 409 | Aldrete 未达阈值 | 继续观察/记录；不得绕过阈值 |
| 页面 403/404 | 无权限/数据范围外 | 找管理员授权；404 是防泄露，不是故障 |

## 8. 临床安全要求

- 系统是记录与辅助工具，**不替代临床决策**；评分阈值以院方最终口径为准；
- 锁单前确认记录完整、签名人正确；修订必须基于事实并留原因；
- 发现记录丢失、签名异常、越权访问，立即停止并上报（P0，2 小时内响应）；
- 不在公共网络/个人设备登录；不转抄真实患者信息到测试环境。
