# ANESOP 速查卡（打印版，贴术间/护士站/质控办）

> 每张卡对应一个角色；步骤编号与培训材料一致。截图占位在正式上线前由实施方补图，
> **不得含真实患者信息**。遇到系统故障：先保证临床，再按
> [`../runbook/EMERGENCY-PLAYBOOK.md`](../runbook/EMERGENCY-PLAYBOOK.md) 报障。
> 应急电话（待院方填写）：信息科 __________　麻醉科 __________　总值班 __________

---

## 卡 1：管理员（信息科）

> 截图占位 S1：会话管理页 / 审计查询结果（脱敏）

1. 登录 → 首次改密 → 重新登录；
2. 会话管理（`/m0/sessions`）→ 撤销异常会话；
3. 建号/授权走管理员接口或变更单：角色最小权限 + 数据范围绑定（ROOM 必绑）；
4. 审计：`sys_audit_log` 按时间/对象/traceId 查；只读、不导出 PHI；
5. 每日：`/healthz`、`/actuator/health`、备份成功、证书 ≥30 天；
6. 发布按 `GO-LIVE-CHECKLIST`；异常按 `ROLLBACK`（≤10 分钟切回上一版本）。

**红线**：不共享管理员账号；不临时给 ALL；不删审计；不把 `.env`/证书入库。

## 卡 2：麻醉医师

> 截图占位 S2：记录单锁单前置清单

1. 登录 → 首页待办 → 申请/排程（只读）；
2. 术前访视：ASA/气道/RCRI/Apfel/STOP-BANG → 麻醉计划 → 保存；
3. 知情同意必须"当前有效 SIGNED"；三方核查按 Time-out/Sign-out 记录；
4. 记录单：开始 → 事件/用药/出入量 → 结束；补录填原因；预警填处理原因；
5. 锁单：核对前置清单 → 勾选确认 → 提交；409 按 `details[]` 补齐；
6. 锁单后只读；修订走"新建修订"+原因码，不直接改；
7. PACU：Aldrete 达阈值才可转出；随访 24/48h。

**红线**：锁单前核对签名人；不绕过同意/核查；不修改设备原始值；不把患者信息带出。

## 卡 3：麻醉护士 / 手术室护士

> 截图占位 S3：专册登记 + 双人核对

1. 登录 → 核对本班术间/台次；
2. 麻精专册：选药品/台次/数量 → **双人核对（不同人）** → 提交（append-only）；
3. 专柜交接：逐项数量/空安瓿/残液 → 双人签字；
4. 记录单麻精用药：第二人登录确认药品/剂量/时间/用法；
5. 耗材：入库（批次/效期）→ 出库绑定台次/记录 → UDI 扫描；重复/过期按提示处理；
6. 随访：24/48h NRS/PONV/并发症/PCA → 提交；异常立即报医师。

**红线**：不代签/补签；同一人不能双人核对；账实不符先报告，不"先交后补"。

## 卡 4：质控专员

> 截图占位 S4：质控指标 + 手算对照

1. 登录 → 质控指标（`/m4/qc/indicators`）→ 选区间/维度；
2. 看指标值 + 分子/分母 + 口径版本；
3. 抽 1 个指标手算对照，差异记录原因；
4. 不良事件（`/m4/qc/adverse-events`）：登记 → 调查 → RCA → 复核（非本人）→ 闭环；
5. 病历抽查（`/m4/qc/chart-reviews`）：评分/缺陷 → 整改 → 复查；
6. 导出 CSV：确认无 PHI、BOM、列头；导出留审计。

**红线**：不手工改库修数；不导出患者标识；复核人不等于登记人。

---

## 卡 5：大屏 / 驾驶舱

> 截图占位 S5：实时看板全屏

1. 登录 → 实时看板（`/m5/dashboard`）/ 风险大屏（`/m5/dashboard/risk`）；
2. 确认"更新时间"在 10–30 秒内（10s 轮询）；
3. 暂停/继续/立即刷新在右上角；
4. 看术间状态、超时台次、告警级别；P1 电话、P2 企业微信、P3 邮件；
5. 大屏不显示患者身份；需要细节到有权限页面看；
6. 停更/空白：先刷新，再查网络/会话，按 runbook 报障。

**红线**：大屏账号只读；不登录管理员；拍照/录屏不得含患者信息。

## 通用：首次登录与常见拦截

| 现象 | 处理 |
|---|---|
| 首次登录只能改密 | 改密后重新登录（`must_change_password`） |
| 429 | 等 `Retry-After` 秒，不要连续重试 |
| 403 | 缺权限/范围外 → 找管理员，不借账号 |
| 404 | 对象不存在或不在范围（防泄露）→ 核对对象 |
| 409 | 冲突/状态不符（锁单/日结/重复）→ 按提示查现状 |
| 页面空白 | 刷新 → 查网络 → 报障；临床记录先纸质兜底 |
