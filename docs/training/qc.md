# 质控专员培训（R8 / SYS_QC_MANAGER）

> 目标：能按院方口径查看/核对质控指标，登记不良事件并完成 RCA 与闭环，做病历质量抽查，
> 正确导出（脱敏）上报文件。
> 权限：`m4:qc:read`、`m4:qc:write`、`m4:qc:review`、`m4:qc:export`；报表另需
> `m4:report:read`/`m4:report:export`。数据范围按角色（ALL/DEPT）裁剪。
> 关联：指标口径见 `docs/modules/m4/README.md` §质控；验收 ACCEPTANCE §A M7。

## 1. 登录与指标查看（`/m4/qc/indicators`）

1. 登录；进入"质控指标"；
2. 选择统计区间（默认近 30 天；以页面/契约为准）与维度（全院/科室）；
3. 查看指标值、分子/分母、口径版本与更新时间；
4. 与手算抽样对照：至少抽 1 个指标，按分子/分母复算，确认一致；
5. 指标目录为全院配置，不按数据范围裁剪；结果按数据范围裁剪。

## 2. 不良事件与 RCA（`/m4/qc/adverse-events`）

1. 新建不良事件：选择类型/级别/发生时间/科室/台次（按权限与范围）；
2. 填写事件经过（只写必要临床信息，避免直接标识）；
3. 提交后进入调查：补充事实、涉及人员、即时处置；
4. 完成 RCA：根因分析（人/机/料/法/环）、改进措施、责任人、期限；
5. 提交复核（需 `m4:qc:review`，且复核人不能是登记人本人）；
6. 复核通过后闭环；整改措施完成后更新状态并留痕；
7. 严重事件按院方制度时限上报，系统导出仅作辅助。

## 3. 病历质量抽查（`/m4/qc/chart-reviews`）

1. 新建抽查：选择台次/病历、抽查表版本、抽查人；
2. 按条目评分/判定缺陷类别（完整性、时效、签名、一致性等）；
3. 提交抽查结果；缺陷汇总到整改；
4. 复查：整改后再次抽查，形成前后对照；
5. 抽查记录 append-only；修正新增记录，不覆盖。

## 4. 报表与导出（`/m4/reports`、质控导出）

1. 工作量报表：选日期范围/维度（科室/术间/人员/术式等），核对合计；
2. 质控上报导出：选指标/区间 → 导出 CSV；
3. 导出文件为 UTF-8 BOM、首行列头；不含患者姓名/住院号/手机号/自由文本；
4. 每次导出写 `QC_EXPORT`/`REPORT_EXPORT` 审计（数据行数，不含明细）；
5. 导出文件按院方要求加密/受控流转，禁止外发到个人网盘/外部模型。

## 5. 口径与变更

- 指标口径/版本由院方确认后配置；变更须记录版本与生效时间，历史结果不追溯改写；
- 发现指标异常先查：数据完整性（未记录台次）、时间范围、数据范围、口径版本；
- 不手工改库"修数"；数据修复走变更单并留审计；
- 报表与质控数字不一致时，以口径定义 + 分子/分母复算为准，记录差异原因。

## 6. 常见错误与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 指标为空/偏小 | 区间无数据、数据范围裁剪、未记录台次 | 放大区间/核对范围；查未记录台次 |
| 手算与系统不一致 | 口径版本/分母不同/时间边界 | 对照口径与分子分母；记录差异，不直接改数 |
| 导出 403 | 缺 `m4:qc:export`/`m4:report:export` | 申请最小授权；不要借用他人工号 |
| 导出列少/乱码 | 权限裁剪/未按 BOM 打开 | 用 Excel/UTF-8 打开；确认权限 |
| RCA 无法复核 | 复核人=登记人/缺 review 权限 | 换复核人；申请权限 |
| 抽查重复 409 | 同台次同表已抽查 | 查已有记录，走复查而非重复创建 |
| 不良事件提交 422 | 时间/枚举/必填不合法 | 按字段提示修正 |
| 看到患者标识 | 违反脱敏/权限异常 | 立即停止、截图留证并上报信息安全 |

## 7. 考核（3 项）

1. 选 1 个指标完成手算对照并说明差异；
2. 登记 1 条不良事件并走完 RCA 提交（演示数据）；
3. 导出一份质控 CSV，确认无 PHI 且有审计记录。
