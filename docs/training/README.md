# ANESOP 培训材料与实施（M6-M20-03）

> 对象：试点医院信息科管理员、麻醉医师、麻醉护士/手术室护士、质控专员、手术室/院领导大屏用户。
> 目标：上线前让每类角色**能独立完成本岗高频操作**，知道出错时找谁、怎么留痕。
> 环境：演示库（SYNTHETIC，`scripts/init-data.sh --mode demo` 或 `scripts/seed-demo.sh`），
> 禁止使用真实患者数据做培训/截图/考核。
> 关联：[`../deploy/GO-LIVE-CHECKLIST.md`](../deploy/GO-LIVE-CHECKLIST.md) §L、
> [`../deploy/DATA-INIT.md`](../deploy/DATA-INIT.md)、[`../guides/demo.md`](../guides/demo.md)、
> [`../runbook/CONTACTS.md`](../runbook/CONTACTS.md)。

## 2. 培训前准备（实施方）

1. 演示库初始化并验证账号（`docs/db/seed.md`，首次登录强制改密）；
2. 投影/测试终端可访问演示环境；准备 2 台终端演示"双人核对"；
3. 准备合成病例：1 台择期、1 台急诊加台、1 条记录锁单后修订；
4. 截图统一在演示环境截，**不得**出现真实姓名/住院号/手机号/人脸；
5. 打印速查卡与签到表；录屏/截图归档到 `docs/training/` 之外的受控目录（不含 PHI）。

## 3. 课程结构（建议）

| 环节 | 时长 | 内容 |
|---|---|---|
| 开场 | 10 min | 系统边界、数据安全红线（患者数据不出院、导出脱敏） |
| 角色演示 | 40 min | 讲师按本角色高频路径演示（编号步骤与速查卡一致） |
| 上手练习 | 40 min | 学员在演示库独立操作，讲师纠正 |
| 异常演练 | 20 min | 断网/权限不足/锁单冲突/重复提交等常见错误 |
| 考核与答疑 | 10 min | 抽查 3 步；登记培训记录 |

## 4. 培训纪律与安全

- 只使用 SYNTHETIC 演示数据；不得把真实病历带入培训环境；
- 不得拍照/截屏含患者信息的页面；示例截图统一用演示账号；
- 口令不共享、不贴便签；首次登录必须改密，离岗锁屏；
- 发现越权/数据异常立即停止操作，按 [`../runbook/EMERGENCY-PLAYBOOK.md`](../runbook/EMERGENCY-PLAYBOOK.md)
  上报，不自行删除/修改数据；
- 培训签到、考核与问题清单由信息科归档，作为上线检查清单 §L 证据。

## 5. 常见共性问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录后菜单很少 | 角色/权限未授予或数据范围为空 | 管理员按岗位授权；ROOM/SELF 需绑定，否则 fail-closed |
| 首次登录什么都不能点 | `must_change_password=true` | 先改密，再重新登录 |
| 页面 403 | 缺权限点或数据范围越界 | 查角色权限与绑定；不要用管理员账号长期代办 |
| 页面 404 | 对象不存在或不在数据范围（防泄露统一 404） | 确认对象与范围；越界不是"再试一次" |
| 记录锁单后不能改 | 锁单后只读，修订走"创建修订" | 按医师手册"锁单与修订"流程 |
| 导出为空/列少 | 无导出权限或时间范围无数据 | 申请 `*:export`；核对日期与口径 |
| 大屏不刷新 | 10s 轮询被暂停/网络断 | 点"继续/立即刷新"；仍异常按 runbook 处置 |

> 详细报错与处置见各角色文档末节；系统级故障见
> [`../runbook/FAULT-PLAYBOOK.md`](../runbook/FAULT-PLAYBOOK.md)。
