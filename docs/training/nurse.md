# 麻醉护士 / 手术室护士培训（R3 / R5）

> 目标：能完成麻精五专的护士侧操作（专册登记、专柜交接、记录单双人核对）、耗材出入库与
> UDI 追溯、术后随访；知道哪些动作必须双人、哪些不能代做。
> 权限：`SYS_NURSE_ANESTHETIST`（麻醉记录/耗材/麻精核对）或 `SYS_PACU_NURSE`（复苏）；
> 五专的日结/基数维护、药品目录维护属药房/管理员职责，护士默认不授予。
> 练习环境：演示库（SYNTHETIC）。

## 1. 登录与班前

1. 登录、首次改密；确认左侧菜单可见"麻醉记录/麻精五专/耗材目录/耗材出入库/UDI 追溯"；
2. 术间终端确认时钟与系统一致（记录时间以服务端为准）；
3. 核对本班术间、台次与人员排班；发现不一致先找手术室管理员，不要自行改主数据。

## 2. 麻精五专（`/m4/narcotic`）

> 五专 = 专人、专柜、专册、专账、专处方。系统落地：专册登记、专柜交接、基数、日结/班结；
> **双人签字必须不同人**（同一人 400）；日结不平不落库（409），差异查清后重新日结。

### 2.1 专册登记（每例麻精使用）

1. 进入"麻精五专 → 专册"；选择药品、台次/记录、数量、用法；
2. 麻精药品强制双人核对：核对人不能是本人，且须具备核对资质；
3. 提交后记录 append-only，不修改/不删除；发现填错按变更单/冲销流程处理，不直接改库；
4. 与麻醉记录单中的麻精用药保持一致，差异在交接时说明。

### 2.2 专柜交接（每班）

1. 进入"交接"页签，选择柜号/班次；
2. 逐项录入交接数量、空安瓿/残液处理；双人签字；
3. 交接后数量应与基数、专册、日结口径一致；不一致不得"先交后补"。

### 2.3 记录单双人核对

1. 在麻醉记录单的麻精用药处发起核对；
2. 第二人登录（另一账号/终端）确认药品、剂量、时间、用法；
3. 核对完成才可提交；同人/缺核对人会被拦截；
4. 核对留审计，不记录患者标识到日志。

## 3. 耗材与 UDI（`/m4/materials`、`/m4/materials/stock`、`/m4/materials/trace`）

1. 目录：按名称/编码查耗材，确认规格、批次、效期、是否高值；
2. 入库：选批次/效期/数量/供应商，提交入库；同批次重复入库会 409；
3. 出库/使用：绑定台次或记录，扫描/输入 UDI；
4. 高值追溯：UDI 反查耗材→记录→台次；重复使用 409、过期 422、退回批次不一致 422；
5. 库存预警：低于安全库存/近效期按提示处理；不要用"先出后补"掩盖差异。

> 截图占位 4：UDI 追溯链（合成 UDI，不含患者标识）。

## 4. 术后随访（`/m2/followups/:recordId`）

1. 按 24h/48h 节点打开随访；
2. 记录 NRS 疼痛评分、PONV、并发症、镇痛方式/PCA 参数与反馈；
3. 自由文本只写必要临床信息，避免身份证/手机号/住院号等标识；
4. 提交后 append-only；需修正按新增记录/修订流程，不覆盖历史；
5. 异常（剧烈疼痛、呼吸抑制等）立即报告医师并记录处置。

## 5. 常见错误与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 双人核对 400 | 核对人与登记人相同/核对人无资质 | 换第二人；确认资质 |
| 日结 409 | 基数+入库−使用−退回 ≠ 期末 | 查专册/交接/退回；差异查清后重新日结，保留两次记录 |
| 专册重复 409 | 同柜同班同日已登记 | 查已有记录；不要重复提交 |
| 入库 409 | 同批次已入库 | 查批次库存；确需调整走变更单 |
| UDI 422 | 过期/批次不一致/UDI-DI 不符 | 核对实物与标签；退回/换批次 |
| 库存为负/预警 | 出库未绑定或盘点差异 | 停止出库，报告管理员盘点 |
| 随访无法提交 | 缺必填/时间节点不符 | 按表单提示；节点未到不要提前 |
| 记录单 403 | 无 m2 记录权限/范围外 | 找管理员授权；不要借他人工号 |

## 6. 安全与纪律

- 麻精操作**双人、实时、如实**；不代签、不补签、不事后编造；
- 只用本人工号登录，离岗锁屏；共享口令按安全事件处理；
- 不把患者信息写入备注/文件名/截图；导出必须脱敏；
- 发现药品/耗材账实不符、记录丢失、越权，立即报告护士长与信息科。
