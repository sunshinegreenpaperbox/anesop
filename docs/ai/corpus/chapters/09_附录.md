## 附录 B AGENTS.md 草案（节选）

规则文件采用"总纲 + 适配层 + 领域层"三段式：AGENTS.md 是被所有工具读取的总纲，CLAUDE.md、.cursor/rules/*.mdc、.github/copilot-instructions.md 只做工具适配，不重复定义规则，避免多套规则冲突。

# AGENTS.md（节选）
 
## 项目
手术麻醉信息系统（ANESOP）。临床记录系统，医疗安全优先。
模块：M0 平台 / M1 排程 / M2 麻醉 / M3 人员 / M4 耗材
/ M5 药品 / M6 工作量 / M7 质控 / M8 驾驶舱。
 
## 硬性红线
1. 禁止将患者数据（姓名、住院号、身份证、影像、文本）
   输入任何外部大模型；仅可使用合成或脱敏数据。
2. 禁止直接向 main 推送；所有改动必须走 PR 并通过 CI。
3. 禁止跳过测试、禁止删除或弱化既有断言。
4. 禁止臆造接口、字段、枚举；以 OpenAPI 与数据库迁移为准。
5. 禁止引入未经白名单审批的依赖。
6. 不替代临床决策；临床规则变更须临床顾问签字确认。
 
## 技术基线
Java 21 / Spring Boot 3.4 / PostgreSQL 16 / Vue 3.5 + TS。
模块间只通过应用服务接口与领域事件通信，禁止跨模块访问表。
 
## 工作方式
先读 docs/specs 与 packages/contracts 再动手；
先写测试或验收用例，再实现；
单次改动尽量 ≤400 行有效代码；
提交信息使用 Conventional Commits，并注明 AI 参与方式。
 
## 自检（提交前）
- ./gradlew check 与 pnpm -r lint typecheck test 全绿
- 涉及数据库：迁移脚本可回滚、含注释
- 涉及接口：契约已更新并通过兼容性检查
- 涉及权限/审计/计费：已列人工复核点

## 附录 D 标签体系与 Projects 字段

标签按"类型 × 领域 × 优先级 × 规模"四维组合，避免标签爆炸：

| 维度 | 标签 | 说明 |
|---|---|---|
| 类型 | type/feature type/bug type/tech type/ai-task type/decision | 决定模板与流程 |
| 领域 | area/platform area/scheduling area/anesthesia area/staff area/consumable area/drug area/workload area/quality area/dashboard area/integration | 对应模块与 CODEOWNERS |
| 优先级 | P0 P1 P2 P3 | P0 阻断发布 |
| 规模 | size/S（≤0.5 天）size/M（1–2 天）size/L（3–5 天）size/XL（需拆分） | 超过 L 必须拆分 |
| 状态 | status/blocked status/needs-review status/needs-clinic | 仅辅助，主状态用 Projects 字段 |

Projects 自定义字段：Status（Backlog/Ready/In Progress/Review/QA/Done）、Sprint（S0–S12）、Module、Priority、Size、Owner、Target milestone、AI assisted（是/否）。
