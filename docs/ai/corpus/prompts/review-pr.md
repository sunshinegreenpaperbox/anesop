# 模板：按医疗系统红线评审 PR

上下文：`AGENTS.fragment.md` + `chapters/04_工程管理与协作机制.md`（4.6/4.7）+ `chapters/05_AI Agents施工约定.md`（5.6/5.7）+ PR diff。

任务：评审该 PR，只输出结论，不重写代码。按以下顺序：

1. 变更范围是否符合任务卡（有无越界改契约、迁移、测试断言）；
2. 临床安全：记录不可变/锁单修订、时间轴、采集断网补传、并发修改、权限与数据范围、审计留痕、麻精药品双人核对——逐项标"过/不过/不适用"；
3. 事务与并发：锁粒度、幂等键、补偿路径；
4. 接口与契约：兼容性、错误码、鉴权；
5. 测试：是否覆盖失败路径，断言是否验证行为；
6. AI 声明与人工复核：高风险七类是否"已逐行"；
7. 性能与可观测性：慢查询、N+1、日志脱敏。

输出格式：`blocking`（必须改）/ `suggestion`（建议）/ `nit`（可选）三级，每条给文件:行号与理由；最后给"可合并/不可合并"结论。
