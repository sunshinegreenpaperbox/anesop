# 模板：契约优先实现一个接口

上下文：`CONTEXT_CORE.md` + `AGENTS.fragment.md` + `chapters/03_总体技术方案.md`（3.2/3.4/3.5）+ `structured/stack.yaml` + `structured/modules.yaml` + 目标模块的契约文件。

任务：实现 `{{HTTP 方法 + 路径}}`，流程固定：

1. 先读契约（OpenAPI）与数据库迁移，复述请求/响应字段、错误码、权限要求；
2. 指出该接口属于哪个模块（M0–M8）、允许依赖哪些模块的 `api`；
3. 给出实现计划：Controller → 应用服务 → 领域服务 → 仓储，事务边界写清楚；
4. 写代码，同时补单测（覆盖正常/边界/越权/幂等）；涉及写库的说明回滚；
5. 更新契约/迁移/数据字典（如需要），并列出受影响的调用方；
6. 自检：编译、lint、单测、契约兼容性。

禁止：跨模块访问对方表或 Mapper；在 Controller 写业务规则；跳过测试；修改契约却不说明兼容性；臆造字段。
输出必须包含"变更文件清单 + 测试命令 + 风险点"。
