# 模板：决策项方案对比

上下文：`CONTEXT_CORE.md` + `structured/decisions.yaml` 中 `{{D-xx}}` + 对应章节（第 3/4/7 章相关节）+ `facts.yaml` 中的假设。

任务：为 `{{D-xx 主题}}` 出一页决策备忘，结构固定：

1. 问题与背景（引用章节号与假设编号，如 A-04）；
2. 选项 A/B/C：各自的做法、代价、风险、可逆性；
3. 评分表：交付风险、合规风险、工期影响、运维成本、可复制性（1–5 分）；
4. 建议与理由：给出一个明确建议，并说明"什么条件下会改选"；
5. 不决策的后果与最晚决策日；
6. 拍板人、需要谁提供输入、落地后要改哪些文档/图/代码。

约束：不得编造客户信息或金额；与方案书已有结论冲突时明确标出；引用必须落到章节号或结构化文件。
