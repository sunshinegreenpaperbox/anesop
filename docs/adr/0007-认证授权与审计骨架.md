# ADR-0007 认证、授权与审计骨架

- 状态：已接受
- 日期：2026-11-12
- 决策人：自动施工代理（按 AUTONOMY §2 默认决策）
- 关联：S0-07 / 方案书 §3.9（安全设计）/ §2.1.2 角色 / auth.yaml 0.3.0 / D-05 / EXT-05

## 背景与约束

S0-07 要求 JWT/SSO 占位、RBAC + 数据权限、审计切面、登录接口、越权用例；验收
"登录→拿 token→访问受保护接口；越权 403 且记审计；单测覆盖正常/越权/过期"。
同时 M1 退出准则与 ADR-0003 要求补齐 Java 契约类型生成。约束：Docker 不可用、
无 Redis/RabbitMQ 实例、无 CA/SSO 环境（EXT-05）、患者数据不出院、不得引入未审批依赖。

## 决策

1. **Java 契约类型生成**：新建 Maven 模块 `apps/api/api-contracts`（parent=apps/api），用
   `openapi-generator-maven-plugin 7.10.0`（Apache-2.0）在 **构建期** 从 4 份契约生成 Java
   DTO 到 `target/generated-sources/openapi`（generateModels=true / generateApis=false /
   generateSupportingFiles=false、Spring 生成器、Jackson、Jakarta EE、Bean Validation、
   openApiNullable=false）。**生成物不入库**（不手工改、随构建再生，避免双源漂移）；
   `scripts/gen-contracts.sh --java` 提供显式生成与校验入口。插件版本最终收敛到根
   `pluginManagement`（本 ADR 提交时同步完成）。
2. **JWT 与令牌（安全评审 B-1 修复后）**：access token HS256、15 分钟；refresh token 7 天、
   **数据库只存 SHA-256**、条件更新实现轮换（并发只有一次成功）、登出撤销 jti 与 sid。
   HS256 密钥：必须 Base64、解码后 ≥32 字节；**拒绝占位/示例值（CHANGE_ME/EXAMPLE/
   PLACEHOLDER/TODO/整词 secret）、拒绝低熵（唯一字节 <8）**；`allow-dev-generated` 默认
   false，仅 dev/test 显式 true（自动生成）；缺失/不安全拒绝启动，错误信息不回显密钥。
   jti 吊销用进程内 `AccessTokenRevocationStore`（接口化，Redis 实现留 M1，多实例部署前
   必须切换）。
3. **口令与会话（B-3/S-2/S-3 修复后）**：BCrypt（spring-security-crypto）；失败计数由单条
   原子 UPDATE 累加（`failed_attempts+1` + `CASE WHEN >=5 THEN now()+30min`），并发不可绕过；
   账号不存在走固定假哈希（计时侧信道）；锁定过期原子清零；停用/锁定/非本地认证统一 **422
   模糊文案**（details 为空，不暴露账号状态）；`must_change_password=true` 时服务端只放行
   me/logout/password，新增 `POST /v1/auth/password`（旧口令 + 强度 12–128、四类取三、不含
   账号/旧口令），契约 0.3.0 additive；refresh token 表 `sys_refresh_token` 由 V3 创建
   （token_hash、issued_at、expires_at、revoked_at、sid、client_info），不依赖 Redis。
4. **授权**：JWT claims 的 roles/permissions 映射为 `ROLE_*` 与 `PERM_*`；`/v1/auth/login`、
   `/v1/auth/refresh` permitAll，其余 authenticated；`/sessions` 要求 `PERM_m0:read`；
   权限码 `<模块>:<资源>:<动作>`（如 `m0:read`、`anesthesia.record.lock` 口径写入
   docs/modules/m0/README）。数据范围 `DataScope`=ALL/SITE/DEPT/ROOM/SELF（与 auth.yaml
   0.2.0 一致），`DataScopeResolver` 当前占位（SYS_ADMIN→ALL，其余→SELF）；**默认拒绝**
   原则：未识别范围不放行；绑定表（用户-科室/术间）在 M1 补。
5. **审计（S-1/S-4/S-5/S-10 修复后）**：`@Audited` 注解与 `AuditWriter` 接口在 m0-api，
   AOP 切面/JdbcAuditWriter 在 m0-impl（模块边界不越界），写 `sys_audit_log`（复用 S0-06 的
   jsonb/inet TypeHandler），覆盖登录成功/失败、刷新、登出、越权（ACCESS_DENIED），登出审计
   归属到 actor/sid；成功路径审计失败 **fail-open**（ERROR 日志 + `auth.audit.failures` 指标，
   响应不变），失败路径也留痕；detail 只落异常类名/白名单短文案（禁止 SQL 实参/凭据泄漏）；
   `X-Trace-Id` 与审计 trace_id 一致（当前服务端生成，跨服务透传 M1）。未认证 401 审计按
   IP+路径 1 分钟采样，登录/刷新有内存令牌桶限流（429）。
6. **错误处理**：统一 `ApiExceptionHandler` 输出契约 `Error`（code/message/traceId/details），
   401 `AUTH_UNAUTHORIZED`、403 `AUTH_FORBIDDEN`、400 校验错误；不泄露堆栈/SQL/内部信息。
7. **生产安全守卫（B-2 修复后，fail-closed 默认）**：守卫**不依赖 profile**——
   `anesop.security.demo-accounts-allowed=false` 默认，启动时 `username LIKE 'demo\_%'` 命中
   即拒绝启动（dev/test 显式 true）；JWT `allow-dev-generated=false` 默认。新增
   `application-prod.yml`：springdoc 关闭、actuator 仅 health/info、Flyway 仅
   `classpath:db/migration`（不含 demo）、日志收紧；base `application.yml` 同等收紧并移除
   `spring.profiles.default=dev`。
8. **R1–R11 角色映射**：V2 已落 6 个平台角色码，映射表写入 `docs/modules/m0/README.md`；
   其余角色/权限码在 M1 实施基线时补，**契约与 seed 以映射表为准**，不在本阶段臆造。
9. **SSO/CA 占位**：AD/LDAP/CAS 与 CA 签名接口只留适配器接口与文档，标 BLOCKED-EXTERNAL
   （EXT-05），不实现真实联调。

## 备选与放弃理由

| 备选 | 放弃原因 |
|---|---|
| 引入 JJWT/Nimbus 直接依赖 | 用 Spring Security OAuth2 Resource Server（Boot BOM 管理）自带 Nimbus，少一个直依赖与版本 |
| Redis 保存 refresh/吊销 | 无 Redis 实例且引入运行时依赖；DB 表 + 进程内吊销满足单实例 M1，Redis 留接口 |
| Java 生成物入库 | 双源漂移风险；构建期生成 + 契约门禁（spectral/oasdiff/drift）更可靠 |
| 用 H2 跑认证集成测试 | MPL 白名单外且 SQL 语义不同；用嵌入式 PG16 |
| 默认放开数据范围 | 违反最小权限；改为默认拒绝 + 显式范围 |

## 后果（正面/负面/代价）

- 正面：JWT + RBAC + 审计 + 生产守卫闭环，安全评审 3 项 blocking 已修复并有测试；
  **78 个测试**（api-contracts 4、m0-impl 28、bootstrap 46）；契约实现一致
  （auth.yaml 0.3.0 / baseline / TS / Java DTO 同源）；Java codegen 补齐 ADR-0003 缺口。
- 负面：SSO/CA/Redis 吊销/多实例会话/并发会话上限/data_scope 绑定表/phone 写路径留 M1；
  springdoc 导出与 baseline 的全量 drift 留 M1；X-Trace-Id 尚未跨服务透传；JWT 吊销单实例
  语义；限流为单实例内存桶。
- 代价：apps/api reactor 增 api-contracts 模块与 25 个测试，verify 时间上升；生成物
  每次构建重新生成（约数秒）。
- 解除条件：院方统一身份/CA 接口（EXT-05）；Redis 就绪后切吊销实现；M1 补 data_scope
  绑定表与全量 springdoc drift 检查。
