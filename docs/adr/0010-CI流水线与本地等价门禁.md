# ADR-0010 CI 流水线与本地等价门禁

- 状态：已接受
- 日期：2026-11-12
- 决策人：自动施工代理（按 AUTONOMY §2 默认决策）
- 关联：S0-04 / AGENTS「提交、PR 与评审」/ docs/branch-protection.md / EXT-08

## 背景与约束

S0-04 要求 GitHub Actions：lint、typecheck、单测、契约（spectral/oasdiff）、构建、
SAST（Semgrep）、依赖与许可证、密钥扫描、镜像扫描、E2E 冒烟；缓存与超时；10 分钟内
（单 job）；验收"PR 上 10 个必需检查可见、故意制造红灯能被阻断、缓存命中"。约束：
**当前无 GitHub 远端、无 `act`、Docker 不可用**；工作区 home 只读、缓存必须在仓库内；
`main` 尚无远端保护可配置。

## 决策

1. **单工作流 10 个 job**：`.github/workflows/ci.yml`，job `name` 与
   `docs/branch-protection.md` 必需检查逐字一致：`ci/lint`、`ci/typecheck`、
   `ci/unit-test`、`ci/contract`、`ci/build`、`ci/sast`、`ci/deps-license`、
   `ci/secret-scan`、`ci/image-scan`、`ci/e2e-smoke`；`permissions: contents: read`、
   `concurrency` 取消旧运行；lint/typecheck/contract 超时 10 分钟，unit/build/e2e 20 分钟，
   image 30 分钟；触发 `pull_request` / `push(main)` / `workflow_dispatch`。
2. **工具链一致性**：所有 Maven 调用走 `./scripts/mvn.sh`（JDK 21 temurin + 仓库内
   `.m2repo` + `-Danesop.root`）；Node 22 + pnpm 11；单元测试 job 执行根 reactor
   `mvn -B verify`（Checkstyle/SpotBugs/JaCoCo 全覆盖）与 `pnpm test:unit`（Vitest 覆盖率）。
3. **缓存**：`.m2repo`（Maven 本地仓库，仓库内）、`.pnpm-store`、`.playwright`
   （浏览器）；键含 lockfile/pom 哈希；缓存路径与本地约定一致，避免 CI 与本地双轨。
4. **SAST 范围**：Semgrep（`p/default`）扫描 `apps/`、`services/`、`packages/`、
   `db/migration`；`deploy/` 不纳入 SAST，由 `ci/image-scan` 与部署评审覆盖。已知
   `deploy/compose/web.Dockerfile` 缺 `USER`（nginx master root）属官方镜像绑定 80/443
   所需，登记为部署评审例外（`docs/ci/audit-exceptions.md`、`docs/deploy/README.md` §13），
   M6 前切非 root 镜像关闭。
5. **依赖与许可证**：`docs/ci/check-deps-license.py` 对照 `docs/deps/allowlist.md` 白名单；
   `pnpm audit --audit-level high` + Maven 依赖检查；**devDependencies 漏洞例外**
   （glob GHSA-5j98-mcp5-4vw2、tinypool 2 条）登记在 `docs/ci/audit-exceptions.md`，
   **到期 2026-12-18**，需升级 vitest 工具链；生产依赖要求 0 high/critical。
   负向测试：未登记 critical、过期 baseline 均能 exit 1（门禁非恒真）。
6. **镜像扫描**：Trivy 构建 api/web 镜像并扫描；Docker 不可用（EXT-08）期间镜像构建步骤
   `continue-on-error`（显式注释、唯一允许项），其余步骤失败即红；解除条件写入文档。
7. **本地等价**：`scripts/ci-local.sh`（`--fast` / `--job <name>`）按同一顺序执行
   lint/typecheck/unit/contract/build/e2e；不可用工具（semgrep/gitleaks/trivy/docker）
   打印 `SKIP`（CI 中执行）但**不掩盖真实失败**；本地 `--fast` 实测 9m13s 全绿，
   `--job ci/build` 59s、`--job ci/e2e-smoke` 7s。
8. **文档**：`docs/ci/README.md` 记录 job 矩阵、缓存键、超时、secrets（无）、EXT-08
   豁免项、首次远端接入步骤、SAST 范围与例外；`docs/branch-protection.md` 只同步
   实际 job 名与映射，审批规则不变。
9. **不可信环境说明**：无远端时无法验证"PR 上 10 个检查可见/缓存命中/故意红灯阻断"，
   以 YAML 静态校验 + 本地等价执行 + deps 负向测试替代；**首次接入真实远端后必须
   补跑并校准**（记入验收遗留）。

## 备选与放弃理由

| 备选 | 放弃原因 |
|---|---|
| 多工作流拆分（ci/security/e2e） | 必需检查名分散、状态汇总复杂；单文件 10 job 更易与 branch-protection 对齐 |
| 自建 runner/act 本地跑 | 无 Docker/无 act 安装；本地等价脚本已覆盖主要门禁 |
| 把 deploy/ 纳入 Semgrep 并抑制告警 | 抑制规则会掩盖真实问题；范围限定 + 例外登记更透明 |
| 立即升级 vitest 修 devDeps 漏洞 | 可能引入测试框架不兼容；以到期例外登记，M1 前统一升级并回归 |
| image-scan 直接跳过整个 job | 保留 job 结构与构建步骤，仅构建在无 Docker 时容错，解除后可立即生效 |

## 后果（正面/负面/代价）

- 正面：10 个必需检查与分支保护逐字对齐；本地有其等价实现且已全绿；依赖/许可证门禁
  可负向失败；SAST/密钥/镜像扫描结构完整；缓存路径统一到仓库内。
- 负面：**尚未在真实 GitHub 远端运行过**（无远端）；Semgrep 远端规则集可能漂移；
  devDeps 漏洞例外与 allowlist 历史缺口有到期日（2026-12-18）；`ci/image-scan` 在
  EXT-08 期间不产生真实扫描结果；Playwright 浏览器依赖镜像源。
- 代价：CI 单 job 最长 20–30 分钟（并行后总体目标 ≤10 分钟需实测）；本地 `ci-local`
  约 9 分钟，与 `check.sh` 功能重叠（`check.sh` 为快速全量、`ci-local` 为 CI 等价）。
- 解除条件：建立远端并启用 required checks → 补跑 10 检查、验证缓存命中与红灯阻断；
  升级 vitest 工具链清除 devDeps 例外；Docker 可用后跑镜像扫描；M6 前关闭 nginx root 例外。
