# ADR-0002 静态检查与提交规范

- 状态：已接受
- 日期：2026-11-12
- 决策人：自动施工代理（按 AUTONOMY §2 默认决策）
- 关联：S0-03 / AGENTS.md「编码与测试要求」「提交、PR 与评审」/ `docs/deps/allowlist.md`

## 背景与约束

S0-03 需要让"本地产出即符合 CI 门禁"：ESLint + Prettier + vue-tsc、Checkstyle + SpotBugs、
EditorConfig、commitlint、`scripts/check.sh` 一键门禁，且验收要求"故意违规能被拦下、
check.sh 全绿、耗时 <3 分钟"。方案未规定规则集细节（行宽、Javadoc、ESLint 规则档位、
hook 启用方式），按 AUTONOMY §2 选可逆、与现有代码一致的做法并记录。环境：home 只读、
JDK 21、Maven 本地仓库在仓库内、Docker 不可用。

## 决策

1. **Prettier 以现有代码为准**：`semi:false`、`singleQuote:true`、`printWidth:100`、
   `trailingComma:all`、LF。现有 `apps/web/src` 零改写；`*.md` 由 `.prettierignore` 排除
   （避免打乱中文表格与语料），`apps/web/src/views/HomeView.vue` 临时排除（其 `<style>`
   多值 font-family 被强制折行，属 S0-08 重建页面文件，届时统一格式化后移除豁免）。
2. **ESLint 9 flat config**：`@eslint/js` 推荐 + typescript-eslint 推荐（non-type-checked，
   骨架阶段控制耗时）+ `eslint-plugin-vue` flat/recommended + `eslint-config-prettier`
   收尾；`no-debugger`=error、`no-console`=warn、`eqeqeq`/`prefer-const`/`no-var`=error；
   生成物（`apps/web/src/api/generated/**`）、依赖与缓存目录忽略。
3. **Checkstyle = Google 风格裁剪版**：4 空格缩进、行宽 160、不强制 Javadoc（中文注释
   合法）、tab/未使用 import/花括号/空白/命名=error，IllegalCatch=warning；只检查
   `src/main/java`（测试源码不纳入），绑 `validate` 阶段。规则文件放
   `config/checkstyle/checkstyle.xml`，由 `scripts/mvn.sh` 注入 `-Danesop.root` 定位。
   **构建必须走 `./scripts/mvn.sh`**；裸 `mvn` 从模块目录执行会找不到规则文件（已在
   README/branch-protection 记录）。
4. **SpotBugs**：effort=Max、threshold=Medium、排除文件仅含占位噪声（不豁免真实缺陷），
   绑 `verify` 阶段。代价：全量 verify 25s→132s，是 check.sh 耗时主因；S0-04 在 CI 用缓存
   与 job 并行缓解。
5. **commitlint + hook**：`@commitlint/config-conventional`；`type-enum` 采纳
   Conventional 全集，`scope-enum` = AGENTS 枚举 + `repo`（仓库级配置/脚本/根文件，
   本 ADR 同步更新 AGENTS.md 与 `docs/branch-protection.md` 的 scope 列表），
   `header-max-length`=100（body/footer 不限行宽，保证 AI trailer 长行不被强制折行），中文 subject 关闭 `subject-case` 检查。hook 用
   `core.hooksPath .githooks` + `scripts/install-hooks.sh` 显式安装（不强制、不写 home）。
6. **`scripts/check.sh` 七步门禁**：后端 verify（含 Checkstyle/SpotBugs）→ pnpm
   frozen-lockfile → ESLint+Prettier → vue-tsc → 前端单测 → 契约 spectral（无契约跳过）
   → `scripts/check-rules.sh`；任一失败立即非 0 并打印失败环节，打印总耗时。
   当前实测 149–155 s（2m29s–2m35s），在 3 分钟验收线内但余量小。
7. **`scripts/check-rules.sh`**：适配层漂移（`CLAUDE.md`、`.cursor/rules/`、
   `.github/copilot-instructions.md`、`.github/instructions/` 只允许指向 AGENTS.md 的
   指针，不得含规则正文）+ 临时条款过期（`TODO(TEMP`/`TEMP:` 带 `expires=YYYY-MM-DD`）。
8. **仓库格式基线**：`.editorconfig`（UTF-8/LF/2 空格，Java 4 空格，Markdown 保留行尾），
   `.gitattributes`（统一 LF、二进制标注、`pnpm-lock.yaml` linguist-generated）。
9. **依赖白名单**：新增 12 个 npm devDependency 与 3 个 Maven 构建插件已登记
   `docs/deps/allowlist.md`；Checkstyle/SpotBugs 为 LGPL-2.1 构建期工具，按 AGENTS
   登记"需法务结论"，不随产品分发。

## 备选与放弃理由

| 备选 | 放弃原因 |
|---|---|
| 用 Google `google_checks.xml` 原样 | 强制 Javadoc/行宽 100 会与中文注释、现有代码冲突，且大量改动非 S0 目标 |
| ESLint type-checked 规则集 | 骨架阶段需全量类型信息，lint 耗时与配置复杂度不划算，后续按需升级 |
| husky 管理 hooks | 引入额外依赖与 home 写入风险；`core.hooksPath` 零依赖且可逆 |
| SpotBugs effort=Default | 漏检多；Max 虽慢 100s 但在 3 分钟线内，CI 再并行 |
| 用 H2 做后续集成测试 | MPL-2.0 不在直接依赖白名单；改用 Zonky 嵌入式 PostgreSQL 16（Apache-2.0 + PostgreSQL License） |
| Prettier 直接格式化全仓库 | 会重排中文 Markdown 语料与业务文件，超出写域且制造噪声 |

## 后果（正面/负面/代价）

- 正面：本地一条命令等价 CI 主干门禁；违规在提交前被拦截；规则文件单一来源
  （`config/`、`eslint.config.js`、`commitlint.config.cjs`）；依赖有台账。
- 负面：check.sh 约 2.5 分钟，接近验收线；SpotBugs 是主要成本；`-Danesop.root`
  使裸 Maven 调用不安全（必须走 `mvn.sh`）；`HomeView.vue` 暂时豁免格式化（S0-08 移除）。
- 代价：Maven 下载 Checkstyle/SpotBugs 插件与规则依赖；pnpm lockfile 增加约 1700 行；
  提交必须符合 Conventional Commits（hook 在安装后生效）。
- 后续：S0-04 在 CI 中把后端/前端拆 job 并行并缓存 `~/.m2`（仓库内 `.m2repo`）与 pnpm
  store；S0-11 加 Vitest/JaCoCo 覆盖率门禁；S0-08 移除 `HomeView.vue` 的 Prettier 豁免。
