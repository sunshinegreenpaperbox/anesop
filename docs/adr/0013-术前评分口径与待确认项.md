# ADR-0013 术前评分口径、阈值配置与待临床确认项

- 状态：已接受（阈值口径部分待临床确认）
- 日期：2026-11-13
- 决策人：自动施工代理（按 AUTONOMY §2 默认决策；临床口径标注待确认）
- 关联：M2-M4-01 / 方案书 §2.4.3 / AGENTS 临床规则高风险

## 背景与约束

M2-M4-01 实现术前访视与风险评分（RCRI、Apfel、STOP-BANG、DASI、ASA、Mallampati）。
独立评审确认公式与公开量表一致（RCRI 6×1、Apfel 4×1、STOP-BANG 8×1 且 3/5 切点、
DASI 12 项权重合计 58.2、`0.43×DASI+9.6`、`<10.23 ≈ <4 METs`；ASA I–VI、Mallampati
I–IV），但**风险合并切点与部分引用存在版本差异**，且方案书未逐条冻结临床阈值。
AGENTS 要求临床规则由临床顾问定口径、人工逐行复核；自动施工不得替代临床决策。

## 决策

1. **实现范围**：评分仅由服务端 `PreopScoreCalculator` 计算，客户端只提交条目；
   `scores` 在契约中 `readOnly`，客户端提交的 scores 被忽略并重算。
2. **公式与引用**：RCRI（Lee 1999 六项）、Apfel（四项）、STOP-BANG（八项，切点 3/5）、
   DASI（12 项 Hlatky 权重，0–58.2；`0.43×DASI+9.6`；`<10.23/≈<4 METs` 为高危参考）、
   ASA I–VI、Mallampati I–IV。Javadoc 记录来源。
3. **阈值可配置**：切点、DASI 4METs 界限、风险合并方式集中在
   `anesop.m2.preop.*` 配置（默认值=当前实现），评分快照写入 `calculatorVersion`；
   调整阈值不改代码、需评审并升 `calculatorVersion`。
4. **风险命名**：综合展示值改称**"最高单项风险"**（不是复合评分），并注明 PONV/OSA
   高危也参与取最高；DASI<34（Wijeysundera 2020）作为待确认补充阈值，不默认启用。
5. **待临床确认（必须回写）**：
   - Q-1：RCRI 0/1/≥2 与 Apfel 0–1/2/≥3 的合并切点；README/Javadoc 中"3.9%/6.0%/≥10%"
     的引用需核实（Lee 1999 常引 0.4/0.9/6.6/11%，3.9/6.0/10.1 更接近 Goldman 1977）；
   - Q-2：DASI<34 是否纳入；"最高单项风险"文案是否满足临床使用；
   - Q-3：V2 种子 SYS_ANESTHESIOLOGIST 为 SELF，看不到 HIS/手术室创建申请（待 M3 分派）；
     护士 finalize 是否需医师复核（M3 双签）。
6. **数据完整性**：术前访视的患者姓名/年龄/住院号**由申请快照服务端回填**，不信任客户端
   携带值（不一致 400）；`FINALIZED` 行由数据库触发器保证不可 UPDATE/DELETE
   （与 V7/V9 append-only 纪律一致），修改只能新建版本。
7. **上线闸门**：术前评分属临床规则，生产启用前必须由临床顾问逐项确认第 5 条并签字；
   自动施工阶段以 SYNTHETIC 数据验证，不做临床有效性结论。

## 备选与放弃理由

| 备选 | 放弃原因 |
|---|---|
| 把阈值硬编码为 static final | 临床口径未确认且可能按院方调整；不可配置会导致每次变更改代码 |
| 用单一复合风险分（如 RCRI 权重和） | 无院方口径依据；改为展示单项最高并标注组成 |
| 客户端计算评分 | 双源漂移、可被篡改；服务端唯一计算 |
| 允许护士独立 finalize | 可能涉及临床责任边界；M3 双签前只允许录入 DRAFT/由医师 finalize（待确认） |
| 用真实患者数据验证评分 | 违反患者数据不出院红线；只用 SYNTHETIC |

## 后果（正面/负面/代价）

- 正面：评分公式可追溯、可配置、有版本；最终化不可篡改；患者快照不可被客户端改写；
  待确认项集中登记，便于临床顾问一次性确认。
- 负面：默认切点仍是工程选择而非院方确认；"最高单项风险"可能被误读为复合评分；
  SELF 范围导致麻醉医师暂时无法访视 HIS 申请（M3 前限制）。
- 代价：每次阈值调整需升 `calculatorVersion` 并回归；临床确认前不得用于真实临床决策。
- 解除条件：临床顾问签字确认 Q-1/Q-2/Q-3；M3 完成人员分派/双签；1.0.0 前将确认后的
  口径固化为契约描述与文档。
